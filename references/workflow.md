# 生产门禁

## G0 项目与实验启动

读取配置、最近一次成熟复盘和当前内容需求。登记本期目标、唯一实验变量、必须保留项、指标和已获授权范围。

通过条件：配置校验通过；实验变量不超过一个；上传与发布权限没有被推断。

## G1 候选与研究

为候选记录日期证据、来源质量、画面性、权利风险和结论。入选事件至少有一个接近原始记录的来源，并尽量交叉确认。

通过条件：重要数字可追溯；事件事实、时期背景和后来结果没有混写；素材的授权与现场属性已记录。

## G2 脚本与承诺

先写本期独有的事实、数字或冲突，再补必要背景。封面只承诺一个可核验事实，并在配置规定的时间内兑现。初稿完成后删除重复结论、空泛升华和不适合口播的书面句，但不得改变事实边界。

通过条件：开头进入时间、承诺兑现时间和目标时长符合配置；没有同义案例堆叠；互动问题可直接回答。

## G3 分镜与 styleframe

为每幕写主信息、事实分类、视觉焦点、信息任务、素材、来源、进入/退出、动效意图、动作落定后的停留和安全区风险。

在完整实现前制作低成本 styleframe，覆盖开场、信息最密集处和高潮/收束中的至少两类。

通过条件：一幕一个主信息和一个主焦点；静音观看仍能理解；不是上一期换字复用；动效没有改变事实结构。

## G4 素材与声音

将渲染资产保存到本地，保留比例与授权记录。声音按场景或语义段组织，音效使用“场景起点 + 相对偏移”，避免前序修改导致整条时间线漂移。

通过条件：离线可渲染；素材不拉伸；口播清楚；峰值与口播/BGM 差值满足配置；关键画面、口播和音乐在同一落点。

## G5 关键帧

渲染开场稳定帧、每幕最密集帧、布局变化后的稳定帧、高潮切入与落定帧、收尾稳定帧。

通过条件：无重叠、遮挡、拉伸、错误单位或越过安全区；视觉评分达到配置阈值；逐帧结果可复现。

## G6 局部预览

只渲染受影响区间：布局问题看对应场景，转折问题看前后各一小段，配音问题看对应音轨范围，转场问题看相邻场景边界。

通过条件：动作、字幕、声音在连续播放中成立。

## G7 完整预览与独立终检

先看低成本完整预览，检查信息顺序、字幕连续、声音平衡、封面承诺兑现和中段重复。通过后再执行独立终检。

终检检查：动效是否帮助理解、参考是否完成平台化改造、证据是否稳定可读、画面/字幕/旁白/BGM/SFX 是否同步、是否出现无意义装饰或模板化镜头顺序、是否只改变了登记的变量。

## G8 高清与平台 UI

执行项目的 lint、类型检查、测试、完整解码、分辨率、帧率、时长、编码和音频峰值校验。再用平台草稿、私密预览或模拟截图检查 UI 遮挡。

通过条件：所有技术命令退出码为 0；关键文字、人物、数字和来源不被平台 UI 遮挡。

## G9 待发布包

从结构化 package spec 复制正式资产，写 manifest 和 SHA-256，再运行独立校验。正式路径只能指向待发布包，不能指向临时渲染目录。

通过条件：所有必需文件存在、非空、哈希匹配；版本和时长有效；构建与校验均返回 0。

## G10 发布后复盘

按配置的早期和成熟时间点记录平台原值。先排除上传事故，再诊断链路中唯一最弱环节。下一条只改变一个变量，其余写入保留项。

达到成熟时长、最少重复次数、最少题材覆盖并完成反证后，才把候选规则升级为稳定规则。
